## ✨ 玩法指南

打开网页后，你可以尝试以下互动：

1.  **🕯️ 许个愿吧**：
    *   在输入框里写下你的新年愿望。
    *   点击“许好了”，准备迎接惊喜。

2.  **🌬️ 吹灭蜡烛**：
    *   对着麦克风 **轻轻吹气**，就像真的吹蜡烛一样。
    *   如果麦克风没反应，也可以点击下面的小按钮帮忙吹灭哦。

3.  **🎁 拆礼物**：
    *   愿望发送后，点击那个跳动的礼物盒。
    *   看看会有什么惊喜发生？

4.  **🪄 隐藏彩蛋**：
    *   试试用手指或鼠标在屏幕上画画？
    *   左上角可以切换 **白天/黄昏/夜晚** 模式，每个时间段都有不同的风景。
    *   右上角的音乐开关，可以控制背景音乐。
